# Evaluation Domain Selection

## Selected Evaluation Domain

**Agentic AI**

### Why This Domain Was Selected

The Minimum Viable Product (MVP) of the Vendor Decision-Support Tool will focus on evaluating enterprise software vendors through the **Agentic AI** evaluation domain.

Agentic AI has emerged as a significant capability across enterprise software, enabling AI systems to autonomously plan, reason, use tools, retrieve information, and execute multi-step tasks with minimal human intervention. Rather than being limited to a single software category, agentic capabilities are increasingly incorporated into products spanning enterprise search, customer relationship management, data management, identity verification, conversational AI, and other domains.

This makes Agentic AI an ideal evaluation domain for demonstrating the reusable framework. Instead of comparing vendors solely within one software category, the framework assesses heterogeneous vendors against a common set of Agentic AI evaluation criteria. This approach reflects real-world consulting scenarios, where organizations often compare solutions based on specific capabilities rather than identical product classifications.

The reusable architecture separates a vendor's primary software category from the evaluation domain, allowing the same framework to support future assessments across additional capabilities without requiring structural changes to the system.

### MVP Focus

The MVP will implement:

* One evaluation domain: **Agentic AI**
* Multiple vendors from different software categories.
* A standardized Agentic AI evaluation criteria set.
* Rule-based weighted scoring.
* Persona-driven recommendations.
* Interactive analytics through Power BI.

Future versions of the framework can introduce additional evaluation domains while reusing the same architecture, database, ETL pipeline, and scoring methodology.
