# Target User Persona

## Primary User

**Role:** Pre-Sales Consultant / Solutions Consultant

### Profile

The primary user of this tool is an internal pre-sales or solutions consultant responsible for evaluating enterprise software vendors and recommending the most suitable solution based on a client's business requirements. These professionals bridge the gap between technical capabilities and business needs, helping prospective customers make informed purchasing decisions.

### Responsibilities

* Understand the client's business objectives, challenges, and technical requirements.
* Compare multiple enterprise software vendors using standardized evaluation criteria.
* Adapt recommendations based on different client priorities and industry-specific needs.
* Present objective, evidence-based comparisons during discovery sessions, demonstrations, and proposal discussions.
* Support sales teams with transparent and consistent vendor evaluations.

### Goals When Using the Tool

* Reduce the time required to compare multiple vendors.
* Replace static spreadsheets and presentation decks with an interactive evaluation system.
* Generate consistent, explainable, and repeatable recommendations using a documented scoring methodology.
* Adjust evaluation priorities to reflect different client scenarios without rebuilding comparison documents.
* Improve the quality and credibility of software recommendations through a structured, data-driven approach.

### Pain Points

* Manual preparation of vendor comparison documents.
* Repetitive updates as vendor capabilities evolve.
* Inconsistent evaluation methods across different consultants.
* Difficulty justifying recommendations with transparent scoring.
* Time-consuming customization of comparison decks for different clients.

### Expected Benefits

The tool enables consultants to evaluate vendors across different software categories through configurable evaluation domains, standardized criteria, and weighted scoring. This approach improves consistency, reduces manual effort, supports reusable assessments, and provides clear justification for every recommendation.
