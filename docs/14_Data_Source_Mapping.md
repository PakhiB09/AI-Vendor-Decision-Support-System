# Data Source Mapping

## Overview

To ensure that vendor evaluations are objective, transparent, and reproducible, every evaluation criterion must be supported by publicly available evidence.

This document identifies the primary sources that will be used during the data collection phase. Rather than relying on subjective opinions or marketing claims, vendor assessments will be based on official documentation and trusted external sources whenever possible.

The actual research and evidence collection will be performed during Step 17.

---

# Source Priority

When evaluating vendors, information will be collected using the following order of priority.

| Priority | Source |
|----------|--------|
| 1 | Official Product Documentation |
| 2 | Technical Documentation & Developer Guides |
| 3 | Official Product Demonstrations & Release Notes |
| 4 | Industry Analyst Reports (Gartner, Forrester, IDC) |
| 5 | Customer Case Studies |
| 6 | Trusted Review Platforms (G2, Gartner Peer Insights, etc.) |

When multiple sources are available, higher-priority sources take precedence.

# Data Collection Guidelines

The following guidelines will be followed during data collection:

- Prefer official vendor documentation whenever possible.
- Validate vendor claims using independent sources where appropriate.
- Do not assign scores based solely on marketing material.
- Record the source used for every evaluated criterion.
- If sufficient public evidence is unavailable, the criterion will be marked as **Not Evaluated (N/A)** in accordance with the scoring methodology.

---

# Outcome

This document establishes a standardized approach for collecting vendor information. By defining the sources used for each evaluation criterion before research begins, the project ensures that vendor comparisons remain consistent, evidence-based, and reproducible throughout the evaluation process.
