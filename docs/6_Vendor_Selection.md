# Vendor Selection

## Vendor Selection Approach

The Vendor Decision-Support Tool evaluates enterprise software vendors through the **Agentic AI** evaluation domain. The selected vendors are intentionally drawn from different software categories to demonstrate that the framework compares solutions based on a common capability rather than their primary product classification.

The vendor list represents a balanced mix of cloud providers, enterprise application vendors, AI platforms, and specialized software providers with publicly documented Agentic AI capabilities.

---

## Why These Vendors Were Selected

The selected vendors satisfy several objectives:

* They represent diverse enterprise software categories.
* Each vendor publicly demonstrates Agentic AI or autonomous workflow capabilities.
* They provide sufficient publicly available information for objective evaluation.
* Together they illustrate how Agentic AI is becoming a capability embedded across enterprise software rather than a standalone product category.

This diversity validates the reusable architecture of the Vendor Decision-Support Tool by showing that vendors with different primary functions can be assessed using the same evaluation framework.
